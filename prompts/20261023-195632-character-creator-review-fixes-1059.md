## Key decisions

**Captured hair gets its own `hair.capturedFringe`** (default 1, the
library's 0.3–2 range) instead of a SPEC_VERSION 3 bump. Before #1059 the
captured branch ignored the lock styles' `fringe`, and the panel keeps that
value across style switches. A separate field restores the old output with no
migration. The fixture gained two specs (captured + fringe 0.5; Funko +
captured + fringe 1.4) generated by the PRE-#1059 codegen (591cde4), so the
byte-identity test proves the old output, not the new one.

**Injection:** `encodeSpecComment` escapes U+2028/U+2029 (JSON.parse reads
the `\u` escapes back, so the header round-trips). `fmt` also escapes them in
string literals. `print.text` gets an allow-list: Unicode letters, numbers,
punctuation, symbols and plain space, with at least one non-space. That also
rejects whitespace-only text at validation time. `pose.preset` gets maxLen 32.
Audit of the other strings: colours are hex-validated, and every other string
is a validated enum. All of them reach the body through `fmt` only, and the
header through the escaped JSON. A unit test runs `new Function(code)` with a
stub api on hostile text in both print.text and pose.preset (separators,
quotes, backslashes, `*/`, newlines). It asserts nothing injected runs and
the spec round-trips. Reverting the header escape makes it fail.

**Save race:** a `saving` flag is set before the confirm dialog. `preview()`
and a firing debounced preview no-op while it is set and queue one immediate
preview for after the save, so an edit made mid-save still shows.

**Nits:** a "Sole: same as footwear" button resets `colors.sole` to null. The
panel's own hover classes are gated with `[@media(hover:hover)]:`. Without
footwear the sock ends at the ankle (bone fraction 1, not 1.1). The schema's
print list carries `maxItems: 6`.

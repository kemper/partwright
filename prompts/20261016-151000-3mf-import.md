## Key decisions

**Pure parser, no new dependency.** The repo has a STORE-only zip writer but no
reader, so a small ZIP reader (`src/import/zipReader.ts`) uses the native
`DecompressionStream('deflate-raw')` and handles ZIP64 extras (Bambu's miniz
writer emits them). The model XML is read by a hand-rolled tag scanner rather
than DOMParser: it keeps a 40 MB Bambu object file to ~1.5 s and lets the whole
parser run in the vitest tier.

**One merged mesh through the existing STL placement flow.** Build-item and
component transforms (including production-extension `p:path` files) are baked
into a single world-space mesh in mm, recentred on XY (Bambu places items at bed
coordinates; z=0 stays the plate). Reusing `placeImportedMesh` keeps the
import-target modal, weld-ladder and render-only fallback identical to STL.

**Colours become paint regions, not code.** Two colour sources: slicer projects
(Bambu/Orca `model_settings.config` + `project_settings.config`, Prusa
`Slic3r_PE_model.config` + `Slic3r_PE.config`, per-triangle `paint_color` /
`mmu_segmentation`) resolve to filament slots; plain 3MF uses `basematerials` /
`m:colorgroup`. Because `Manifold.ofMesh` reorders triangles, seed regions are
resolved after the import runs (a function seeder) by nearest-centroid mapping,
colouring only exact matches so a compose-into-current-object import leaves the
existing geometry alone. Split-painted triangles take the majority filament
(new `dominantPaintColorState`), since Partwright paints whole triangles.

**Palette capture.** The file's filament list becomes a named palette made
active, with each region bound to its slot (so re-export maps back onto the same
AMS slots). An identical palette with the same name is reused to avoid pile-up
on re-import; adoption happens lazily inside the seeder so cancelling the target
modal never creates one. `importMeshData` accepts 3MF (with `adoptPalette:
false` to opt out) for UI/API parity.

**Skipped geometry.** Bambu modifier/negative/support parts and Prusa
non-ModelPart volumes are skipped (they aren't printed geometry); negative
volumes are not subtracted — noted as a limitation.

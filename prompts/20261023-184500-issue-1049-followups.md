## Key decisions

**findFaces.** Omitting every filter still means "the whole mesh", as documented. A key that is present but `undefined`/`null`, or an unknown key, is now an error. The check lives in a small pure module so it can be unit-tested. The AI tool schema declared `region` as a string while the API wanted an integer; it is now an integer.

**probePixels(pixels, view).** One camera and one cached BVH serve every pixel. Pixels may be `[x, y]` or `{x, y}`. The model's pixel bounds are projected at most once and returned when any pixel misses. The batch limit is an advanced setting.

**Persisted refine (schema 1.21).** This follows the `surfaceTexture` model:
- What is saved: the live refined working mesh, plus `toRoot` from the mesh lineage. `toRoot` already carries labels, parts and explicit ids across the refinement.
- Key: base mesh content + refine descriptors + label sizes.
- When it is saved: only when the mesh matches the current refine set and no smooth image stamp exists. Stamps replay on top of the restored mesh, so persisting them would double-refine.
- On load: a matching key replaces `refineForRehydrate`, and a diagnostic-log info entry records it (the e2e test checks for that entry). A stale or malformed entry just rebuilds.
- All 7 migration spots are updated, `trimForShare` strips the field, and old files still import.

**Boundary paint.** `partBoundary` chains the edges shared by an A-triangle and a B-triangle into ordered loops. Vertices are matched by quantized position, so meshes with split vertices still chain. `paintAlongBoundary` resamples each loop and paints it as one smooth `paintStroke`. For `side: a|b` the stroke uses radius = width plus `withinPart` of that side, so the band's edge lies exactly on the seam. The seam is computed on the run's label mesh. Draft parts must be accepted first, consistent with `withinPart`.

**Seeds.** A `maxRadius` cap needs to know which seed reached a triangle, so the growth heap now carries a seed index instead of a label. A capped seed's frontier is confined to its precomputed geodesic ball. The cap is wired through:
- `resolveSeeds`, `crease-watershed` and seeded thickness;
- the draft's split, pin re-grow and pin moves;
- validation, the AI schemas and the docs.

Random-walker only uses growth as a reachability warm start, so it does not honour the cap; the docs point to `paintAlongBoundary` for ungrooved bands instead. `previewSeeds` reports for each seed:
- the landing triangle;
- the closest surface point;
- the distance and a miss flag (threshold in config);
- the draft part there.

It works without a draft.

**renderParts / compare.**
- `views` takes names or `{azimuth, elevation}`, plus an azimuth/elevation shorthand. The AI tool uses a separate `angles` array, because the schema avoids a string-or-object union for Gemini.
- `focus` frames the camera on the part's padded bbox through a new `frame` option on `buildViewCamera`. The near plane follows the focus box; the far plane covers the whole mesh.
- Compare captions list the params that differ between configs of the same detector, or what differs from the defaults for a detector that appears once. Long captions wrap.

**Also fixed.** The `partAt` AI tool sat in no gating set, so the chat AI could never call it outside plan mode. It and the new read tools are now always available.

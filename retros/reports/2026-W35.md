# Retro Report — 2026-W35

**Entries reviewed:** 11 (one — the catalog-refresh batch — itself aggregates
structured feedback from 16 independent rework agents, so the effective
sample is closer to 26 agent-sessions)  ·  **Span:** 2026-07-03 → 2026-07-20

## What's working (preserve these)

- **`model:preview` as the inner loop.** Cited repeatedly as the thing that
  turns geometry bugs into a look-and-fix loop instead of trial-and-error
  (blender-parity-verbs, catalog-refresh, mesh-to-code). Multi-angle
  `--view "az,el;az,el"` tiling + native `sharp` crops made verification
  cheap for 16 rework agents in one batch. Don't regress this workflow.
- **`work-reviewer` earning its keep.** Caught a real regression missed by
  hand-written e2e (part-grouping: collapsed-group drag no-op) and a
  serialization-format diff blowup (blender-parity-verbs: `json.dump`
  indent mismatch). Keep launching it before marking PRs ready.
- **Deciding integration architecture before writing code.** blender-parity-
  verbs: scoping which of 8 features fit the Worker sandbox with zero schema
  risk, up front, paid for itself repeatedly. multi-part-assembly-view: the
  pure-module-first split (`layout.ts`, `sharedParams.ts`) let the trickiest
  logic land fully unit-tested before any DOM/Three.js was touched.
- **Parallel disposable-context subagents for iteration-heavy work.**
  model-sculpt subagents (5 showcase models, up to 65 tool calls each) and
  the inverse-CAD PLAYBOOK-ratchet subagents (21 + 16 parts across three
  sessions) both kept expensive render/probe loops out of the orchestrator's
  context while compounding a shared knowledge base turn over turn.
- **The spec-driven browser screenshot as the highest-value verification
  step**, called out independently by multi-part-assembly-view and
  3mf-packing-strategy — it caught wiring bugs (a pool that never resolved,
  edit tools acting on a hidden part) nothing else would have.

## Top friction (ranked)

1. **[docs/tooling] Region-scoped `round`/`smoothWeld` (2 agents, catalog-refresh
   batch).** Welding a thin fin to a large body forces the lattice over the
   whole model. → **Applied**: documented the "local weld" workaround recipe
   in `public/ai/deform.md`. A first-class `region`/bbox option is still a
   backlog item (see below).
2. **[tooling] `scatter` placement feedback (4 agents, catalog-refresh batch).**
   `count` is a request, not a guarantee, and the only signal is counting
   dots in a PNG. This already quadruples the vote on existing issue #928 —
   see backlog.
3. **[tooling] Inverse-CAD orchestration bookkeeping (3 independent sessions:
   inverse-cad-v2, benchy-foreign-mesh, inverse-cad-armor-genericity).** No
   driver distinguishes "agent finished" from "best exists," so a part can
   silently go unassigned (armor_shoulder) or get baked from an interim,
   still-improving result. Recurring ask across all three inverse-CAD
   sessions this batch — see backlog `status.mjs` proposal.
4. **[tooling] Warm-browser loop for UI iteration (2 sessions this batch —
   multi-part-assembly-view, 3mf-packing-strategy — each noting "same wish
   as prior retros").** Every UI screenshot round pays a cold ~4s WASM boot
   + session rebuild inside a fresh Playwright run. The repo already solved
   this for model geometry (`bin/partwright.mjs daemon start`); no
   equivalent exists for driving the actual app UI. See backlog.
5. **[docs] `src/main.ts` NUL-byte trap — muscle memory gap (1 agent,
   3mf-packing-strategy).** CLAUDE.md already warns about the binary file,
   but the agent still tried the `Grep` tool with `-a` (unsupported) before
   falling back to `Bash grep -a`. → **Applied**: clarified that the `Grep`
   tool doesn't support `-a` at all, so go straight to `Bash`.
6. **[docs] `showToast` call signature ambiguity (1 agent, mesh-to-code-in-app).**
   Existing CLAUDE.md prose implied but never stated the exact signature,
   costing a typecheck round-trip. → **Applied**: spelled out
   `showToast(message, { variant, log, source })` explicitly.
7. **[tooling] Offset-vs-instance-thickness math for `scatter` (3 agents,
   catalog-refresh batch)** and **thin-feature radius limits for `round`
   (3 agents, catalog-refresh batch)** — both want a worked numeric example /
   rule of thumb in `deform.md`. Left as backlog rather than applied: the
   agents proposed a number ("radius ≈ 4–6% of edge length") they hadn't
   themselves verified as a general rule, and I don't have the data to
   confirm it — writing it into the doc as fact would risk shipping a wrong
   rule of thumb. Whoever builds the `scatter`/`round` follow-up tooling
   should validate and document the actual numbers empirically.

## Changes applied in this PR

- `CLAUDE.md`: clarified the `src/main.ts` NUL-byte section — the built-in
  `Grep` tool doesn't support `-a` at all; go straight to `Bash grep -a`/
  `rg -a` rather than trying `Grep` first.
- `CLAUDE.md`: spelled out `showToast`'s exact call signature
  (`showToast(message, { variant, log, source })`) so it's no longer
  guessable-wrong from prose alone.
- `public/ai/deform.md`: added a "Region-scoped round / smoothWeld" section
  documenting the clip-weld-restitch workaround recipe for local-only welds,
  addressing the two-agent ask from the catalog-refresh batch.

## Backlog (needs a human or the tooling/linter agent)

- [ ] **`scatter` placement feedback** — a `placedCount` stat, a dry-run mode
  returning anchor points, and a documented overshoot heuristic. Raised by 4
  agents this batch on top of existing issue #928 (now 4× the original
  vote) — highest-priority code change in this report.
- [ ] **First-class `region`/bbox option on `round`/`smoothWeld`** so the
  local-weld recipe (now documented in `deform.md`) becomes a single call
  instead of a 3-step manual clip/weld/restitch. Raised by 2 agents.
- [ ] **Inverse-CAD convergence driver (`scripts/inverse-cad/status.mjs`)** —
  a status table + auto-refill + completion detection so an orchestrator
  managing ~20 parallel part agents can't silently under-launch (armor_shoulder)
  or consume a moving `best/` from an agent that hasn't actually finished.
  Companion ask: `turn.mjs` should stamp the `gates.mjs` version into
  `best`/`metrics` and warn when a stored "passing" result predates a gate
  change (inverse-cad-v2). Raised across 3 independent inverse-CAD sessions.
- [ ] **Warm-browser UI iteration harness** — analogous to the existing
  render daemon for model geometry (`bin/partwright.mjs daemon start`), but
  for driving the actual app UI: open the editor once, keep WASM hot, drive
  `window.partwright` + screenshot per iteration instead of paying a cold
  Playwright boot every round. Raised by 2 sessions this batch, both noting
  it echoes prior retros — this is now a recurring, multi-cycle ask.
- [ ] **A single trustworthy component/part counter** — engine `decompose()`,
  the app's statsComputation count, and a welded-mesh census disagree on
  degenerate meshes (and `decompose()` flip-flops run to run). A headless
  "count it all three ways and explain disagreements" tool would cut a
  debug loop that currently costs ~8 bake round-trips. Raised by
  multipart-kits-overview.
- [ ] **Headless CLI twin of `convertToCode`** (`partwright convert
  <file.stl>`) so mesh→code quality-knob tuning doesn't require a
  Playwright loop, plus a worker-side progress channel into the "Rendering…
  Xs" indicator for the levelSet phase. Raised by mesh-to-code-in-app.
- [ ] **Headless build-plate-layout rasterizer** — the packing equivalent of
  `model:preview`: render parts-as-footprint-rects on the bed to a PNG
  instead of only asserting bed-bounds numerically from parsed 3MF XML.
  Raised by bambu-plate-layout-packing.
- [ ] **Repo-wide "readiness-poll instead of fixed wait" test helper**
  (e.g. `waitForEngineReady(page)`) to retire a class of intermittent
  `waitForTimeout`/modal-race shard flakes (paint-cancel #912,
  threemf-multipart #911 both trace to this pattern). Raised by
  3mf-packing-strategy.
- [ ] **`surface-exposure` stat for labels** — "fraction of label surface
  exposed" would make buried-paint bugs (a healthy `triangleCount` while
  actually invisible, as happened with the toadstool's spots) gate-able
  headlessly instead of only visually. Raised by 1 agent, catalog-refresh
  batch, high value despite single mention.
- [ ] **`genus`-change flag in `model:preview` output** when iterating on one
  model — a fin-weld silently went genus 0→10 and was only caught by manual
  diffing. Raised by 1 agent, catalog-refresh batch.
- [ ] **`api.placeOnFace(shape, {face})`** — flat 2D relief onto one of a
  box's six faces, to replace hand-derived rotation matrices. Raised by 1
  agent, catalog-refresh batch.

## What's working (preserve these)

- **Measure-before-modeling, applied to a metric itself.** The inverse-CAD v2
  rewrite's highest-leverage finding was a 5-line self-distance check that
  exposed a 0.15mm noise floor in the *old* metric — the user's eye had been
  right and the number wrong. Distrust a metric the same way you'd distrust a
  guess.
- **The PLAYBOOK ratchet**: merging each subagent's returned tactics before
  launching the next wave turned 21 (then 37) parts into a tractable single
  session, with per-part turns dropping from 7 → 1 as the recipe matured. This
  is the same cross-agent-frequency principle this retro process itself runs
  on, and it's now validated at framework scale.
- **`model:preview` as the inner loop, again** — every new geometry op in the
  Blender-parity batch was visually verified within minutes of being written,
  and the corduroy-terracing defect in `smoothWeld` was caught by *looking*,
  exactly as the visual-verification doctrine predicts.
- **Structured per-agent retros aggregated with vote counts** (the 16-agent
  catalog-refresh batch) produced sharper, better-prioritized signal than 16
  separate free-form notes would have — worth doing again for the next
  fan-out batch.
- **Explore-agent pre-work mapping before implementing** (part grouping, tool
  history auto-repair, mesh→code reconstruction) continues to pay off —
  already CLAUDE.md doctrine, still the decisive move every time it's used.

## Top friction (ranked)

1. **[inverse-cad] No orchestration/status visibility across parallel convergence agents** — 3 sessions (`20260703-inverse-cad-v2`, `20260704-inverse-cad-armor-genericity`, `20260705-benchy-foreign-mesh`). Three distinct failure modes from the same root cause (nothing tracks convergence state centrally): a part (`armor_shoulder`) was silently never assigned an agent and only caught by a final manual sweep; a gate-code fix (genus convention) silently stale-passed an already-"banked" best until a sibling agent happened to flag it; and a catalog bake consumed an agent's *interim* best because there was no way to tell "agent still running" from "best exists." **Action: backlog** (below) — this needs new tooling, not a doc fix.
2. **[catalog API ergonomics] Converging asks from the 16-agent catalog-refresh batch (#929)** — the batch itself already folded several fixes into `deform.md`/`CLAUDE.md` during the PR (the `round`-first-then-paint rule, `paint.slab`'s one-sided band, `circularPattern`'s origin-relative radius, the `--silent` JSON gotcha). Two remaining doc asks — each raised by 3 independent agents — are applied in this PR (see below): a worked numeric example for sizing `scatter`'s `offset` against instance thickness, and a `radius ≈ 4–6% of edge length` rule of thumb for a "machined" look with `round`. The two remaining *code* asks (region-scoped `smoothWeld`/`round`, and `scatter` placement feedback — the latter already tracked as #928 and now quadruple-voted) are backlogged below.
3. **[UI iteration] Cold Playwright+WASM loop for UI-only changes** — 2 sessions (`2026-07-06-multi-part-assembly-view`, `2026-07-07-3mf-packing-strategy`), the latter explicitly noting "same wish as prior retros." This is distinct from the already-built `bin/partwright.mjs daemon` (which warms geometry *code* iteration) — the gap is a warm loop for arbitrary UI interaction (open panel, click, screenshot), which nothing in the repo currently provides. **Action: backlog.**
4. **[testing] Rail/list drag specs silently miss off-screen rows at the default viewport** — 1 session (`20260706-part-grouping`), but precise and cheap to fix. **Action: applied** — added to `docs/playwright-guide.md`'s AI agent gotchas.
5. **[figures/labels] A label can carry a healthy triangle count while being visually buried or off-camera** — 2 votes across different mechanisms: the catalog-refresh batch's toadstool bug (spots technically painted, invisible under the cap) and the Blender-parity session's cropped mug lettering (camera-facing, not burial, but the same "stats say fine, render says otherwise" shape). **Action: backlog** — a surface-exposure stat and/or an off-camera-label warning in `model:preview`.

## Changes applied in this PR

- `public/ai/deform.md` (scatter section): added a worked example for sizing `offset` against an instance's own half-thickness along its normal-aligned axis — the exact miscalibration that buried instances in 2 of the 16 catalog-refresh sessions.
- `public/ai/deform.md` (round section): added a `radius ≈ 4–6% of edge length` rule of thumb for a deliberate machined-fillet look, distinct from (and well inside) the existing thin-shell failure-limit caution.
- `docs/playwright-guide.md`: added a 6th AI-agent gotcha — rail/list drag specs need a taller viewport than the 1280×900 default, or target rows sit outside the interactable clip and the drag silently no-ops.

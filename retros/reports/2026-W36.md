Already CLAUDE.md doctrine; reconfirmed.

## Top friction (ranked)

1. **[tooling] No warm dev-server/browser loop for UI iteration** — 2 sessions this batch (assembly-view, 3MF-packing), with the latter explicitly noting "same wish as prior retros." Every verification round pays a cold ~4s WASM boot + fresh session build inside a new Playwright run; a UI feature iterated ~5 times loses minutes of wall-clock per look. The repo already has the analogous pattern for model geometry (`bin/partwright.mjs daemon start` keeps a warm browser for `model:preview`-style renders) — this is the same idea applied to UI screenshots instead of geometry renders. Filed to backlog below; this is a build, not a doc fix.
2. **[docs] `deform.md` had three concrete, agent-requested gaps** — surfaced by the 16-agent catalog-refresh-agent-feedback aggregation: sizing `scatter`'s `offset` against the instance's own thickness (3 agents, two first passes fully buried their instances), no documented recipe for welding a thin feature onto a large body without lattice-ing the whole bbox (2 agents, one agent hand-invented a clip/weld/stitch recipe), and a still-wanted "radius ≈ 4-6% of edge length" rule of thumb for a machined look (3 agents; the underlying thin-shell caution was already added in a prior batch). **Action:** all three added to `public/ai/deform.md` in this PR.
3. **[tooling] `scatter` gives no placement feedback** — 4 independent agents in the catalog-refresh batch hit this (count is a request, not a guarantee; the only signal today is counting dots in a PNG). This quadruples the vote on an already-filed ask (#928: `placedCount` stat, dry-run mode returning anchor points, documented overshoot heuristic). No new issue needed — flagged here so its priority is visible.
4. **[tooling] Inverse-CAD multi-agent orchestration has no driver/status layer** — 3 sessions (v2, armor genericity, benchy) independently wanted the same thing from different angles: a `status.mjs` convergence driver (armor_shoulder was silently never assigned an agent, caught only by a final manual sweep), a `turn.mjs` convention distinguishing "agent finished" from "best exists" so orchestrators don't consume a moving best/ (benchy re-baked from an interim, still-polishing result), and durable-by-default subagent workspaces (converged candidates lived in gitignored `.plans/` on an ephemeral container, rescued only by an explicit copy-and-commit). A related, lower-cost complaint: the `Stop` hook fired ~20 times during long agent waits with nothing to reconcile (armor genericity) — a "background agents in flight" suppression would help. All of this is new tooling/hook surface, not a doc fix — backlogged below.
5. **[tooling] Topology/component counts disagree across measurement paths** — 2 sessions: engine `decompose()`, the app's stats computation, and a welded-mesh census disagree on degenerate meshes and `decompose()` itself flip-flops run to run (multipart-kits-overview, ~8 bake round-trips burned debugging this); separately, mesh-genus vs. solid-genus diverge exactly when a mesh self-touches, and there was no reference tool for it until `voxelGenus.mjs` got built mid-task (benchy). A headless "count/measure it every way and explain disagreements" tool would serve both. Backlogged.
6. **[docs, applied] Playwright rail/list drags silently miss below the fold** — 1 session (part grouping): the parts-list rail is ~55px tall at the default 720px viewport, so drag-targeting e2e missed rows without visible failure until the viewport was set to 1400px. `docs/playwright-guide.md` already has a "Viewport size" gotcha for the AI panel's toggle strip — extended it to cover rail/list drags in this PR rather than adding a new item.

## Changes applied in this PR

- `public/ai/deform.md`: added a worked numeric example for sizing `scatter`'s `offset` against an instance's own half-thickness; added a clip→weld→stitch recipe for welding a thin feature onto a large body without lattice-ing the whole bounding box; added a "radius ≈ 4–6% of edge length" rule of thumb for `round()`.
- `docs/playwright-guide.md`: extended the existing "Viewport size" AI-agent gotcha to cover short scroll-box rails (rail/list drag tests need a taller-than-default viewport), instead of adding a new numbered item.

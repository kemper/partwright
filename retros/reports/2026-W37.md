# Retro Report — 2026-W37

**Entries reviewed:** 12 (aggregating 27 agent sessions — 11 single-session entries plus one entry, `2026-07-20-catalog-refresh-agent-feedback.md`, that itself rolls up 16 sub-agent retros)  ·  **Span:** 2026-07-03 → 2026-07-20

## What's working (preserve these)

- **Pure-module-first, then DOM/UI.** Splitting the hard logic (grid packing, param union, `partTree.ts` threading rules) into dependency-free modules with unit coverage, verified *before* touching Three.js/`main.ts`, kept two multi-round UI features (#893 Assembly view, part-grouping) from regressing through their whole rework.
- **The spec-driven Playwright screenshot check is the highest-value verification step, repeatedly.** Three independent PRs (#893, #910, #904 by extension) credit a throwaway screenshot spec with catching the bugs typecheck/unit couldn't — pool-never-resolving, edit-tools-acting-on-hidden-part, wrong export dialog wiring.
- **`model:preview` as the inner loop for headless geometry/paint iteration** — corduroy-terracing, metal-material-black-in-CI, and 16 catalog-refresh fixes were all caught by *looking* at a render within minutes of writing the op, exactly as the visual-verification doctrine predicts.
- **`work-reviewer` earns its keep.** Caught a real drag-on-collapsed-groups regression the author's own e2e missed (part-grouping) and a 1300-line manifest diff from mismatched `json.dump` formatting (blender-parity).
- **Delegating heavy render-iterate loops to subagents keeps the main context clean and comes back reliable** — 5 parallel model-sculpt agents (blender-parity) and up to 20 inverse-CAD convergence agents (armor-genericity) all returned print/gate-valid results without the caller ever holding their image tokens.
- **The PLAYBOOK ratchet compounds visibly across the inverse-CAD framework** — thigh 7 turns → shin 1 turn → forearm 3 probes + 1 turn; the armor-era recipe then transferred verbatim to a never-seen 3DBenchy mesh. Merging each wave's returned tactics before launching the next is the mechanism, not a side effect.
- **Per-part `expectComponents` gating pays for itself immediately** on multi-part kits — caught simplify-fused pieces, sub-mm debris, and non-deterministic `decompose()` output before anything shipped.

1. **[tooling] No warm browser/WASM loop for UI iteration — 2 sessions this batch, explicitly "same wish as prior retros."** Every verification round on a UI feature pays a cold ~4s WASM boot + session build inside a fresh Playwright run; a 5-round UI feature loses minutes of wall-clock to this alone (#893, #910). → **Backlog** (needs a headless "warm browser" harness, analogous to the existing model-render daemon).
2. **[docs, partially addressed] `scatter` placement feedback — 4 independent sub-agents this batch alone**, quadrupling the existing #928 vote: `count` is a request not a guarantee, the only signal was counting dots in a PNG, and offset-vs-instance-thickness sizing was trial-and-error (two first passes fully buried their instances). → Added a worked numeric example to `deform.md` this week (see below); the `placedCount` stat / dry-run mode / `seat` convenience itself still needs code and stays **backlog** (#928).
3. **[tooling] No headless way to see a packed build-plate layout — 2 independent PRs (#910, #904).** Both verified 3MF/Bambu plate packing by parsing `<item>` transforms out of XML and asserting bed-bounds numerically; neither could *show* the arrangement the way `model:preview` shows geometry. → **Backlog**.
4. **[docs, addressed] `src/main.ts`'s NUL-byte zone keeps costing turns — now 4 sessions cumulative.** This week's instance burned a call on the dedicated `Grep` tool's unsupported `-a` flag before falling back to `Bash`. → `CLAUDE.md` clarified this week (see below).
5. **[docs, addressed] `smoothWeld`/`round` operate on the whole input bbox — 2 agents.** Welding a thin fin to a large body forced a lattice over everything; one agent invented a working clip → weld → stitch-remainders recipe. → Documented the recipe in `deform.md` this week; a first-class `region`/bbox option remains **backlog**.
6. **[docs, addressed] Thin-feature round radius limits are sharper than the doc suggested — 3 agents.** The thin-shell caution was already added in a prior batch; a "radius ≈ 4-6% of edge length for a machined look" rule of thumb was still explicitly wanted. → Added to `deform.md` this week.
7. **[tooling, backlog] Orchestration bookkeeping gaps in large multi-agent convergence sweeps.** `armor_shoulder` silently went unassigned in a ~20-agent wave (armor-genericity) — caught only by a final manual sweep. A driver/status script was proposed in the original inverse-CAD design and still doesn't exist.
8. **[tooling, backlog] No single trustworthy component counter.** Engine `decompose()`, the app's `statsComputation` count, and a welded-mesh census disagree on degenerate meshes (multipart-kits-overview); each disagreement round-trips ~2 minutes through the bake page.

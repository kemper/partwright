## Liked / Worked
- The relief import's `seedRegions` path and `buildCarriedColorRegions` (nearest-centroid
  colour transfer) were exactly the primitives needed: 3MF colours became paint
  regions with a ~20-line function seeder instead of new colour plumbing.
- The existing STL placement flow (`placeImportedMesh` → import-target modal, weld
  ladder, render-only fallback) took a new format by just threading one optional arg.
- `work-reviewer` caught two real robustness gaps (nested-component fan-out to 2^31
  triangles from a 2 KB file; unbounded inflate) with concrete repro files.

## Lacked
- No ZIP *reader* in the tree (only the STORE writer), so 3MF needed a hand-rolled
  one. `DecompressionStream('deflate-raw')` works in Node 22 too, so it unit-tests fine.
- Nothing documents that `Manifold.ofMesh` reorders triangles (it's only a comment
  in the relief import), so precomputed per-triangle ids silently scramble.

## Learned
- `pr-assets/` screenshots follow an add-then-remove convention (`7ae205f` then
  `47e4a3d`), with the PR body linking to the pinned SHA. Plain `git log -- pr-assets`
  shows nothing; you need `--full-history` to see the precedent.
- Bambu `model_settings.config` `<part id>` equals the component `objectid` in
  `3D/Objects/object_N.model`; `<object id>` equals the root build item's objectid.

## Longed for
- An untrusted-file import checklist in CLAUDE.md (expansion budget, decompression
  cap, colour/region-count cap). Every binary importer needs those three guards, and
  reviewers currently have to rediscover them.

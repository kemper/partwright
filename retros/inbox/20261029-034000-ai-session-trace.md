- Mocking Gemini SSE with `page.route('**/v1beta/models/**')` (pattern from
  tests/ai-unpriced-model.spec.ts) drove a real two-call tool turn through
  the agent Worker in ~25s, so the persisted telemetry got a real end-to-end
  test instead of only seeded rows.

  reviewer finding became a ~1s vitest case.

## Lacked
- The "AI Call Log looks empty" report was about how the log is scoped, not a
  bug. It's in-memory, per tab, since page load. Nothing in the UI said so,
  and the first hypothesis had to be ruled out (Worker forwarding already
  fixed in #877).

## Learned
- Compaction deletes the turns it summarizes, so any per-message spend
  accounting has to be rolled onto the summary message or it silently
  vanishes. Its summary also sorts first by seq but is created last, so
  durations must use min/max createdAt.
- Several user-role messages aren't human prompts: carried compaction
  attachments, auto-review follow-ups, and auto-resume nudges.
  `userConversation()` in autoReview.ts has the canonical exclusion list.
- The ai.md turn-0 budget test sits within ~70 chars of its ceiling, so a new
  console-API line has to displace something.

## Longed for
- One shared `isHumanPrompt(msg)` helper in src/ai/. The exclusion list now
  exists in autoReview.ts and sessionTrace.ts and will drift.

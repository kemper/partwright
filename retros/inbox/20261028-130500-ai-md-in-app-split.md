## Liked / Worked
- Measuring before cutting. A line-overlap check (ai.md section vs its readDoc
  subdoc) separated real duplication (iteration-workflow, ~90% verbatim) from
  sections that only *looked* redundant (meshOps, objects/parts, api.params:
  under 10% overlap). Those stayed, so no guidance was silently lost.
- The #1177 "every tool is placed" test immediately caught three tools that
  merged from the Parts work alongside it.

## Lacked
- Concurrent PRs can each pass CI and still break main together: #1177 added
  the placement test while the Parts PRs added unplaced tools. PR checks run
  against the base at push time, not the merge result. Nothing re-tests an
  already-green PR when the base moves.

## Learned
- "HTML comments are invisible to external readers" is only true for the
  rendered page. External agents fetch raw markdown, so any audience-specific
  comment must name its audience ("(In-app chat only.)").
- ai.md already had a dead in-page anchor (`#text--api-text--api-textsection`;
  GitHub drops dots from slugs). The new anchor-resolution test finds these.

## Longed for
- A merge-queue or "re-run checks when base changes" setting for main, so
  semantic conflicts like the tool-placement one fail before merge, not after.
- An agent A/B harness (tracked on #1175) to show the in-app model performs
  no worse with the slimmer prompt. Today the evidence is only "nothing
  needed was removed", checked by hand and by a reviewer.

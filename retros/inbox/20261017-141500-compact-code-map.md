## Liked / Worked
- Writing the permanent golden-path spec first (tests/code-minimap.spec.ts) doubled
  as the manual screenshot check — one artifact for both.
- Launching `work-reviewer` in the background right after the first commit found six
  real should-fix issues (mobile no-op buttons, slide timer surviving a breakpoint
  flip, stuck hover popover) while CI ran.

## Lacked
- ~11 e2e specs assume `document.querySelector('canvas')` / `locator('canvas').first()`
  is the 3D viewport. Adding any canvas earlier in DOM order breaks them silently;
  cost one CI round-trip. Now scoped to `#viewport-container canvas`.
- ~20 specs seed `editorCollapsed` to force the editor visible; any change to
  default pane chrome means a mechanical sweep across tests.

## Learned
- Tailwind `hidden md:flex` on the layout splitter meant `classList.toggle('hidden')`
  never hid it on desktop — `md:flex` outranks `hidden`. Toggle both (see
  `setSplitterVisible` in layout.ts). Grep for other `hidden md:*` toggles.
- Playwright `toBeVisible` treats content inside a `width:0; overflow:hidden` parent as
  visible — assert on the container's bounding box instead.

## Longed for
- A `viewportCanvas(page)` helper in tests/helpers so specs never grab "the first
  canvas"; plus an ast-grep rule flagging `querySelector('canvas')` in tests.
- A `seedEditorPrefs(page, {codeView})` helper so pane-default changes touch one file.

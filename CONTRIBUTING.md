[issues](https://github.com/kemper/partwright/issues). Code and other
contributions are accepted only on the terms below, so please read them before
you open a pull request.

## Before you open a pull request

- **Talk to us first.** Open an issue (or comment on an existing one) and wait
  for a maintainer to agree to the change before you write code. Pull requests
  without an agreed issue may be closed without review.
- **Confirm the terms.** Include this line in your pull request description:

  > I agree to the contribution terms in CONTRIBUTING.md.

  Pull requests without it won't be merged.
- **Keep it focused.** One change per pull request, based on the latest `main`.
- **Follow the conventions.** Use a [Conventional Commits](https://www.conventionalcommits.org/)
  prefix in the title (`feat:`, `fix:`, `docs:`, …) and run `npm run preflight`
  before you push. [`CLAUDE.md`](./CLAUDE.md) describes the architecture, tests
  and project rules in detail.
